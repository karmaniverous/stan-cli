# Meta Archive Refactor (stan-cli implementation)

We have implemented `-m/--meta` behavior in `stan-cli` as follows:

- Context mode (`-c`) no longer produces `archive.meta.tar` unconditionally.
- When `-m` (requires `-c`) is passed:
  - The main `archive.tar` IS the meta archive (system + context + meta/state).
  - Diff generation is skipped (only full meta archive is produced).
  - `archive.tar` is renamed from the meta archive path.
- When `-m` is omitted:
  - `archive.tar` is the full source archive.
  - `archive.diff.tar` is produced normally.

This aligns context mode with the standard artifact naming convention and avoids redundant artifact generation.
